GD+ Proposal · 03 01 — Executive Summary

A website that behaves like the agency it represents.

GD+ already has a disciplined visual system — a defined colour palette, Material 3 shape language, and a clear brand voice around People, Ideas and Possibilities. Our brief was to turn that system into a website that feels current, confident, and a little playful, without straying from the guidelines.

5

Pages

Home, About, Services, Case Studies and Contact — enough to tell the full story without overbuilding.

3

Brand colours, no more

Every card, gradient, icon and highlight on the site is built from the approved primary, secondary and tertiary tokens.

0

Build dependencies

Static HTML, CSS and vanilla JS — no framework, no build step. Easy to hand off, host anywhere, and edit directly.

∞

Room to grow

A component system (cards, buttons, sections) that scales to new pages and campaigns without starting over.

GD+ Proposal · 04 02 — Our Approach

Discover, Design, Build, Refine.

The same four-stage rhythm we'd bring to any GD+ project — applied here to our own process of building the site.

01

Discover

Reviewed the GD+ website guidelines end to end: colour tokens, Material 3 shape and elevation rules, typography scale, and the reference example — treating it as a style guide, not a fixed layout.

02

Design

Translated the guidelines into a working design system — type scale, button and card components, spacing rhythm — then sketched the sitemap and page wireframes shown later in this document.

03

Build

Built all five pages as self-contained HTML files with shared CSS/JS patterns, layering in motion — scroll reveals, magnetic buttons, a kinetic hero, gradient highlights — for a site that feels alive.

04

Refine

Iterated against additional creative references and brand-asset pages as they came in, folding new patterns (flat-colour cards, glow previews, event illustration) back into the shared system.

GD+ Proposal · 05 03 — Creative Direction

On-brand, on purpose.

Every visual decision traces back to the same three colours and the same type family — the personality comes from how they're used, not from adding new ones.

Primary#EC5628
Secondary#5799D2
Tertiary#FFCC02

Official brand gradient — always blue → orange → yellow, never flipped or rotated. Applied to headline emphasis and the wordmark's "G".

  • Kinetic hero — gradient blob with a drifting event illustration
  • Gradient text highlight on one key phrase per headline
  • Flat-colour pillar & team cards, Miro-inspired, GD+ palette only
  • Glow-preview cards for featured case studies
  • Floating sticker badges and a giant watermark "G"
  • Magnetic buttons, scroll reveals, animated counters
  • Confetti burst on contact form submission
  • Public Sans throughout, Material 3 rounded shape language
